Net Buddy Video Uploader

Developed using YouTube API Services

Privacy PolicyTerms of ServiceNet Buddy home

The Net Buddy Video Uploader is a private command-line tool, made by N6WWW, that publishes the Net Buddy tutorial videos to the developer's own YouTube channel. It runs only on the developer's own computer and is not offered, sold or distributed to anyone else.

For each lesson of a tutorial course it uploads the video, sets its title, description, tags and thumbnail, adds it to the course playlist in order, and reads the result back to confirm it.

Privacy Policy

Effective 25 November 2026.

YouTube and Google

  • This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service.
  • Google's handling of your data is covered by the Google Privacy Policy.

What the tool accesses

  • After you sign in with Google and give consent, the tool uses the YouTube Data API to read the signed-in channel's ID, title and handle, and to create and update videos, thumbnails and playlists on that channel only.
  • It reads no viewer data, comments, subscribers, analytics or earnings, and no data about any other channel.

What is stored, and where

  • The Google sign-in token is stored only on the computer running the tool, encrypted by Windows (in Windows Credential Manager, or in a Windows-encrypted file if Credential Manager is unavailable). It is never written to a plain file and never sent anywhere except Google.
  • The tool keeps a small local record of each upload (the file's fingerprint, the video ID and which steps finished) so that a failed run never uploads the same video twice.
  • Nothing is stored on any server. No cookies, analytics or tracking are used.

Sharing

No data obtained through YouTube API Services is shared with, sold or rented to anyone.

Revoking access and deleting data

  • You can revoke the tool's access to your Google account at any time at Google Account › Third-party connections (also reachable at security.google.com/settings/security/permissions).
  • Revoking access makes the stored token useless at once. Deleting the tool's folder and its stored token removes everything the tool stored. When access is revoked, the token and the upload records are deleted within 7 days.
  • Videos and playlists the tool published stay on YouTube until you delete them there.
